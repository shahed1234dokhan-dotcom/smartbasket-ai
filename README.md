# SmartBasket AI — מנוע חישוב (שלב 1)

סימולטור רווחיות לסל קנייה עבור מכולות קטנות. בשלב זה קיים רק **מנוע החישוב** ובדיקות היחידה — בלי ממשק ובלי מודל שפה.

> המדד המרכזי הוא **רווח תרומתי משוער לסל** — לא רווח נקי. לא נכללים שכירות, שכר, מסים והוצאות קבועות.
> כל הנתונים בדוגמאות מדומים.

## נוסחאות (`smartbasket/engine.py`)
| מדד | נוסחה |
|---|---|
| עלות יחידה מתואמת לפחת | `C_adj = C / (1 − d)` |
| הכנסות הסל | `Σ P × Q` |
| עלות מתואמת לפחת | `Σ C_adj × Q` |
| שחיקת פחת | עלות מתואמת − `Σ C × Q` |
| עמלת אשראי | `F + r × הכנסות` (במזומן: 0) |
| רווח תרומתי משוער | הכנסות − עלות מתואמת − עמלה |
| נקודת איזון של הסל | `(עלות מתואמת + F) / (1 − r)` |

ברירות מחדל (`smartbasket/defaults.py`): פחת 1% יבש / 10% חלב-מקורר / 20% ירקות-פירות; עמלה 1.5% + 0.50 ₪;
מחיר קנייה חסר ← 75% ממחיר המכירה (מסומן "אומדן").

החישוב נעשה בערכים מלאים; עיגול לאגורה רק בהצגה (`money()`).

## דוגמה
```python
from smartbasket import Item, PaymentSettings, calculate_basket, money
res = calculate_basket([Item("ירק טרי", "ירקות-פירות", 2, sell_price=9, buy_price=6, spoilage_rate=0.2)],
                       PaymentSettings("card", 0.015, 0.50))
print(money(res.contribution))  # 2.23
```
